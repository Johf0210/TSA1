# TSA1 Submission Checklist

## Required files and features

- `TaskModel` retrieves records from the `tasks` table.
- `UserModel` retrieves the single demo record from the `users` table.
- `/` filters tasks where `task_date` equals today's date.
- `/tasks` displays every task ordered by date.
- `/profile` displays the demo user.
- `/about` identifies the developer.
- `database/schema.sql` creates both tables and inserts the required sample data.

## Submit

1. GitHub repository link containing the raw project files and database export or migration/seeder files.
2. Hosted working application link.
3. Screenshots showing the database records and each working page, if your instructor requests evidence.

## Before submitting

- Replace the developer placeholder in the About page.
- Replace the demo user's placeholder name and email in `database/schema.sql`.
- Make sure at least one task uses the actual current date when you test the Welcome page.
- Confirm the hosted URL matches the code in the GitHub repository.
